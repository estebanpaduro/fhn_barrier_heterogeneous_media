## Generate figures used in the paper: "A Mathematical Characterization of Neural Activation Induced by Temporal Interference Stimulation"

Mathematica notebooks used to generate figures and simulations in the research article: Propagation failure in heterogeneous FitzHugh--Nagumo systems via coupled upper and lower solutions
Authors: Matías Courdurier and Esteban Paduro

## Download 
From a command line:
```
git clone https://github.com/estebanpaduro/fhn_barrier_heterogeneous_media
```

## Contents
The scripts are organized as follows:
* `Fig1.nb`: Generate a figure Illustrating the construction of the barriers on Theorem "Stationary barriers in heterogeneous media".
* `Fig2.nb`: Generate figures describing the numerical experiment associated with the case of "Localized depressed dynamics generated by the additive heterogeneity".
* `Fig3.nb`: Generate figures describing the numerical experiment associated with the case of "Localized depressed dynamics with recovery diffusion".
* `Fig4.nb`: Generate figures describing the Numerical classification of propagation for the additive heterogeneity.
* `Fig5.nb`: Generate figures describing the numerical experiment associated with the case of "Pulse interaction with a single abrupt conductivity transition".
* `Fig6.nb`: Generate figures describing the numerical experiment associated with the case of "Pulse interaction with a localized conductivity reduction".
* `Fig7ab.nb`: Generate figures describing the numerical experiment associated with the case of "Almost stationary barriers and solution evolution for the homogeneous problem".
* `Fig7cd.nb`: Generate figures describing the numerical experiment associated with the case of "Almost stationary barriers and solution evolution for the homogeneous problem".
